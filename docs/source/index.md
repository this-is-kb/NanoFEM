# NanoFEM documentation

Structure follows Diataxis (ARCHITECTURE v1, Section 11):

- `tutorials/` — learning-oriented, runnable end-to-end (arrive with phase 0.5+)
- `howto/` — task-oriented recipes
- `theory/` — one chapter per formulation, mapping one-to-one onto `physics/` subpackages
- `api/` — autodoc reference (Sphinx toolchain lands phase 0.5)
- `adr/` — Architecture Decision Records

Cross-cutting guides: `developer_guide.md`, `architecture_overview.md`,
`package_guide.md`, `coding_standards.md`, `roadmap.md`. Frozen design
documents live in `docs/design/`.
